# Журнал изменений

Все заметные изменения программы. Формат - [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Номер версии - `1.0.<номер коммита, считая с нуля>`: каждый коммит +1, выпуск - тег на коммите
(подробно - CONTRIBUTING.md, «Номер версии»). Поэтому между выпусками номера идут
с пропусками - это нормально.

## [Не выпущено]

## [1.0.9] - 2026-09-24

### Добавлено
- **Тематические колонки для ИТ** (настройки → «Тематические колонки», каждая включается отдельно,
  по умолчанию выключены; Linux и Windows):
  - **Контейнеры** - Docker и Podman: контейнер упал, не хватило памяти (OOM), healthcheck
    «нездоров», перезапуск по кругу («3-й раз за 10 минут»). Ручная остановка карточку не создаёт,
    обычные запуск и остановку можно включить. Программа только слушает события движка;
  - **Службы** - упавшие службы systemd (системные и пользователя) с хвостом журнала; на Windows -
    службы из журнала событий, которые завершились с ошибкой или не запустились;
  - **Команды** - обёртка `messhub run -- команда` (на Windows - `messhub-run.exe`): итог с кодом
    выхода, временем и хвостом вывода. Код выхода команды сохраняется, так что её можно ставить в
    скрипты. Хук терминала теперь тоже кладёт карточки в эту колонку.
- **«Проблема → починилось»**: когда контейнер снова работает, служба поднялась или команда прошла,
  карточка бледнеет и получает «✓ починилось». Своим скриптам то же доступно через приём событий:
  поля `key`, `status: "resolved"` и `details`.
- Хвост лога под карточкой: свёрнут, раскрывается по клику, двойной клик копирует. Хранится только
  в базе и в Telegram не пересылается.
- **Раздел «Логи»**: журнал самой программы (сбор, доска, ошибки страниц) с фильтром по важности,
  поиском, автообновлением, копированием, выгрузкой в «Загрузки» (домашняя папка заменяется на «~»)
  и очисткой. Число ошибок за сутки - рядом с пунктом меню и в «Системе». Журнал сам ограничивает
  свой размер.

### Изменено
- Хук терминала (`long-command.sh`) шлёт уведомления в колонку «Команды». Если раньше им уже
  пользовались, колонка включится сама.

### Безопасность
- Локальный сервер отвечает только своим страницам: запросы с чужим именем сайта в `Host`
  (DNS rebinding), с чужим `Origin` и с пометкой браузера `cross-site` отклоняются. Раньше вредный
  сайт, открытый в браузере, теоретически мог прочитать сообщения с доски.

## [1.0.7] - 2026-09-24

### Добавлено
- **Windows 10 и 11 (бета)**: установщик `.msi`, установка через `setup.bat` и переносная версия `.zip`.
  Уведомления читаются через системный доступ к уведомлениям Windows, доска - на движке WebView2.
  Сборка, установка и удаление проверяются автоматически на Windows; чтение уведомлений - бета.
- В шапке доски - номер версии с отметкой ✓ «последняя» или «↑ новая версия» со ссылкой на выпуск,
  и значок GitHub. Раз в 12 часов программа спрашивает у GitHub номер последнего выпуска (без
  каких-либо данных о тебе); выключается в «Настройки → Система».
- Автор в настройках и в «Системе»; формы для issues: ошибка, новый источник, идея.

### Изменено
- Файлы разложены по папкам: программа - `app/` (страницы - `app/web/`, значки - `app/icons/`),
  сборка - `packaging/` и `tools/`. Обновление из git: `git pull && ./install.sh`.
- README: установка по шагам для всех систем и всех файлов выпуска, проверка контрольных сумм.
- Лицензия: при использовании обязательно указывать автора - «Кузьминский Максим i@m-letto.ru».

## [1.0.3] - 2026-09-24

**Первый публичный выпуск.** Одно окно для всех уведомлений рабочего стола Linux: сообщения из
мессенджеров, почты, браузера и своих скриптов собираются на доску с колонкой на каждое приложение
и хранятся только на этом компьютере.

### Что умеет
- Собирает штатные уведомления рабочего стола (D-Bus): eXpress, Telegram, MAX, WhatsApp и другие
  сайты в браузере, почтовые программы, календарь, свои скрипты и сборки.
- Доска на рабочем столе: колонки по приложениям, сообщения одного чата - одной плашкой, аватары,
  упоминания твоего имени, «прочитано» с отменой, «отложить», «закрепить», режим фокуса, размытие
  для показа экрана, светлая тема. Через сутки прочитанное убирается само.
- Правила «как в почте»: по чату, отправителю и словам - показать, скрыть, подсветить, сразу
  прочитать, закрепить, звук, переслать в Telegram. Профили «Работа», «Дом» по расписанию.
- Почта напрямую из ящиков по IMAP (Яндекс, Mail.ru, Gmail, Outlook, iCloud, свой сервер) или из
  уведомлений почтовых программ - на выбор.
- Поиск по всей истории, по желанию - умный поиск по смыслу через локальную нейросеть (Ollama).
- Статистика, резервные копии, выгрузка в CSV/JSON, недельный отчёт в Telegram, приём событий по
  HTTP, карточка о долгой команде в терминале, самодиагностика, русский и английский интерфейс.

### Установка
- Пакеты: `.deb` (Ubuntu, Debian, Mint), `.rpm` (Fedora, openSUSE) и архив `.tar.gz` с
  `./install.sh`. Команда `messhub` и ярлык в меню; автозапуск включается первым запуском.
  Проверено установкой в чистых Debian 12, Ubuntu 22.04 и Fedora 40.

### Нумерация
- С этого выпуска номер версии - `1.0.<номер коммита>`: каждый коммит +1, выпуск - тег на коммите.

## До публикации - внутренние сборки 1.2 (2026-09-24)

Программа теперь называется **messhub**.

### Добавлено
- Почта напрямую из ящиков по IMAP - раздел настроек «Почта»: сколько угодно ящиков (готовые
  настройки для Яндекса, Mail.ru, Gmail, Outlook, iCloud или свой сервер), проверка подключения,
  «проверить сейчас». Письмо на сервере не становится прочитанным; при подключении ящика старая
  почта не подтягивается. Способ получения почты один: уведомления почтовых программ или ящики -
  чтобы письма не приходили дважды. Колонка «Почта» при этом одна на все ящики.
- Закрыть колонку (крестик в шапке, с подтверждением): её сообщения становятся прочитанными,
  колонка возвращается с новым сообщением. С закреплёнными или отложенными сообщениями закрыть
  нельзя - виджет скажет почему. Там же - «Скрыть насовсем».
- В «Системе» - проверка подключённых ящиков.
- Подготовка к публикации: README на русском и английском со скриншотами всех экранов (на
  вымышленных данных), `tools/demo_data.py` и `tools/screenshots.py` - демо-данные и снимки,
  `tools/check_public.py` - нет ли в репозитории личного (базы, токены, пути),
  `tools/i18n_check.py` - у всех строк есть перевод, шаблоны issue и PR, `SECURITY.md`.
- CI: тесты на Python 3.9, 3.12 и 3.13, проверка переводов и публикации; ветки `main` и `contrib`.

### Изменено
- Имя: eXpress-msgs → messhub. Папки данных - `~/.local/share/messhub`, `~/.config/messhub`;
  сервисы - `messhub.service`, `messhub-widget.service`; переменные окружения - `MESSHUB_*`.
  `./install.sh` сам останавливает и убирает прежние сервисы и переносит данные.
- Esc больше не закрывает виджет (легко было нажать случайно) - только всплывающее меню.
- «Вернуть» после прочтения и «Вернуть в виджет» из поиска снова открывают закрытую колонку.

### Удалено
- Старая страница-лента `index.html` (её заменил виджет, `/` теперь открывает его) и `run.sh`.
- Флаг `collect.py --only-express` и неиспользуемые `/api/unread`, `start_auto_read`.

### Исправлено
- Сообщения скрытых колонок и колонок вне `--only` больше не запрашиваются заново каждые 15 секунд.
- «Перейти в приложение» не путает похожие ярлыки (поиск по `.desktop` требует совпадения имени).
- В меню профиля пункты выровнены по левому краю и не серые.
- Сообщения окна виджета («не нашёл окно», «не удалось открыть») переводятся на английский.
- Перезапуск виджета из «Системы» показывал подсказку «Перезапустить» вместо «Виджет перезапускается…».
- Неверный пароль почты не оставляет висящее соединение.
- Текст в личке с двоеточием («Прошлая версия: ссылка», «Готово? Да: …») больше не принимается за
  имя отправителя.
- Самодиагностика не падает, если база лежит не в папке данных (`--db` в другом месте).
- В форме почты примеры адресов - на зарезервированном домене `example.com`.

## До публикации - внутренние сборки 1.1 (2026-09-24)

### Добавлено
- Поиск по всей истории (без учёта регистра, в том числе кириллица) с фильтрами и кнопкой
  «Вернуть в виджет»; необязательный умный поиск (RAG) по смыслу и ответы на вопросы через
  локальную Ollama - ставится из настроек.
- Профили («Работа», «Дом», …): правило можно привязать к профилю; профиль включается вручную
  из шапки виджета или по расписанию.
- «Почему так?» - какое правило скрыло, подсветило, закрепило или переслало сообщение
  (журнал срабатываний при записи).
- Кнопка «Вернуть» на 5 секунд после любого «прочитать».
- Аватары отправителей из самих уведомлений.
- Перетаскивание и скрытие колонок; второй виджет с отбором колонок (`widget.py --only …`).
- Выгрузка и загрузка правил и настроек в файл; ежедневные резервные копии базы с
  восстановлением из настроек.
- Недельный отчёт в Telegram (цифры без ИИ).
- Приём событий по HTTP с ключом (`POST /api/ingest`), в том числе из сети - отдельным сервером.
- Хук терминала: карточка о долгой команде (`hooks/long-command.sh`, bash и zsh).
- Разделы настроек «Система» (самодиагностика, автозапуск сбора и виджета) и «Справка».
- Английский интерфейс (язык - в настройках или как в системе).
- Упрощённый режим для Wayland.
- Установщик `install.sh` / `uninstall.sh`, тесты, README на двух языках, лицензия Apache-2.0.

### Изменено
- Данные переехали из папки с кодом в `~/.local/share/express-msgs` и `~/.config/express-msgs` (с переименованием - в `…/messhub`)
  (переносятся автоматически при первом запуске; копия старой базы - в `backups/`).
- Юниты systemd собираются установщиком из шаблонов `packaging/systemd/*.in`.

## До публикации - первая сборка с номером, 1.0 (2026-09-24)

Что умела программа на этот момент.

### Сбор уведомлений
- Читает штатные уведомления рабочего стола (D-Bus `org.freedesktop.Notifications`,
  метод `Notify`) и пишет их в локальную SQLite; наружу ничего не уходит.
- Разбирает чат, отправителя и текст: групповые чаты вида «Имя: текст», лички,
  веб-уведомления браузеров по сайту (web.max.ru → MAX, WhatsApp, VK, почта),
  почту Thunderbird/Geary/Evolution (отправитель и тема), календарь.
- Снимает задвоения, отсекает ботов и каналы Telegram.
- Работает как фоновый сервис `systemd --user`.

### Виджет на рабочем столе
- Полупрозрачное окно с колонками по источникам; перемещение и изменение размера
  мышкой, запоминание места; замок - закрепить окно и держать под всеми окнами.
- Прочитать сообщение, чат, колонку или всё сразу; отложить (на час, 3 часа,
  до вечера, до утра); закрепить; через 24 ч после записи - прочитано само.
- Сообщения одного чата сворачиваются в одну плашку; подсветка правилами,
  упоминания (@), режим фокуса - только важное.
- Ссылки открываются в браузере, двойной клик копирует текст, клик по имени
  переключает на окно приложения (или открывает сайт).
- Размытие содержимого для показа экрана; номер версии в шапке.

### Правила и настройки
- Правила «как в почте»: условие - источник (или все), чат, отправитель, текст
  (подстрока или регулярное выражение); действие - показывать, скрыть, подсветить,
  сразу прочитано, закрепить, звук, переслать в Telegram.
- Окно настроек: источники (переименование, режим «только разрешённые», дерево
  «кто писал»), правила для всех, упоминания, внешний вид (прозрачность, шрифт,
  светлая тема, компактный режим), статистика, данные (срок хранения, удаление,
  выгрузка CSV/JSON), пересылка в Telegram.
